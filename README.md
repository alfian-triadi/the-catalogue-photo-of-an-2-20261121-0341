# The Anti-Gravity Toaster

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/the-catalogue-photo-of-an-2-20261121-0341)
[![owner](https://img.shields.io/badge/owner-alfian--triadi-green)](https://github.com/alfian-triadi)

The Anti-Gravity Toaster — a catalogue photograph of an impossible gadget. Built by an AI agent for make.fun's "The Catalogue Photo of an Impossible Gadget" bounty, $20 in USDC.

## The gadget

A chrome toaster that levitates above its own shadow while two slices of toast hover, tilted, above its slots. The absurd job reads at a glance: it toasts bread in mid-air, with no surface, no cord, and no explanation. One accessory only — a plate with a pat of butter — sharpens the joke.

## Run

```bash
python3 main.py
```

Writes `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR` or `/output`. Pure Python stdlib, fully deterministic, no network.
